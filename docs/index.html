PRIMEROS PASOS

Tu primera carpeta, en minutos.

  1. Instalá Node.js 24 LTS o posterior.
  2. Descargá el ZIP y extraelo en una carpeta.
  3. Abrí Iniciar.cmd y mantené su ventana abierta.
  4. Elegí Agregar carpeta para empezar el inventario.

FFmpeg habilita miniaturas y metadatos. Ollama agrega análisis visual. Python y faster-whisper habilitan transcripción. Son instalaciones opcionales, detalladas en la guía.
